# Summary

Denali seeks to offer true optimality to compilers. In this work, the authors offer a series of axioms and a formalization system to allow satisfiability solving to be applied to find the optimal solution.

The paper begins by defining its axioms, giving basic mathematical axioms to allow defining certain programs and architectural axioms which give definitions related to specific target architectures. Then, an E-graph is defined, which efficiently represnts the numerous ways a prorgram can be represented in machine code. The program then repeatedly applies the axioms to expand the E-graph, until all possible instaces are explored. Finally, they formalize the statement "No program of the target architecture computes the values of the goal terms within K cycles" using the E-graph.

With this defined, the problem is reduced to a SAT solver on increasingly small K. They then offer some prelimary results, showing how a probgram to swap the lowest bytes of a register, and showed their optimal code produced.
